### 裁决 · 本轮 P1 **不按回声处理**(弱收敛证据),但 P2 一格不放松

**被解释的条款原文**(`forge-config.md` K 段):

> P1 交换后若两人的预测**都落空**(即又是逐条相同),**本轮 P1 直接按回声处理,不得作为收敛证据。**

**实际发生的形态 —— 该条款枚举之外的第三态**:

| 维度 | 观察 | 指向 |
|---|---|---|
| 六题处置倾向 | 几乎逐条相同(`-04`/`-05`/`-12` 均 refactor · `-11` 均 new · `-09` A=refactor+new / B=refactor;仅元层 A=keep+强化 / B=new) | **像**回声 |
| 四条具名预测 | **互相落空**:A 预测 B 在 `-09` 判排期成本(B 实判规格缺陷)· A 预测 B 在 `-05` 给代理指标(B 实给行为形态)· B 预测 A 会把第四态合法化(A 实判「先修」= 交付物性质改变,未合法化)· B 预测 A 判 `-04` 为三文档同步遗漏(A 实判「登记顶替回写」)。仅 A 关于 `-04`「对方会判程序性/产物性」方向命中 | **不像**回声 |
| 根因论 | `-04` / `-12` / 元层三处**实质不同** | **不像**回声 |

**裁决理由**:该 binding 的**立法意图**是防「两人其实没独立思考」。**预测互相落空恰恰证明双方
不知道对方会怎么判 ⇒ 独立性成立**。结论撞车更可能源于材料本身指向明确;且有一条硬事实是
**B 侧独立复证**的(自行全文查 `market` 仅命中 grain 注释 + T015 六跑零 per-market),
不是从 A 侧转手。按条款字面判回声,会**误杀一个真独立的轮次**。

**⚠ 该裁决不是白给的 —— 两条附加约束,均为 hard**:

**① P2 不因此放松 · 破局器仍然只能是零重叠检索。**
预测落空只证明**双方不会读心**,**不证明不同源** —— 两个模型可能共享同一套先验与训练分布,
从而在「猜不到对方」的同时仍然**同向偏**。因此:

- 双方 P2 **必须申报本轮检索面**(检索了什么、命中什么、哪条结论由哪次检索支撑);
- **任何只复述自己 P1 的结论不计入 P2 收敛证据**;
- 本仓语料已有的 PEP 387 / RFC 1589 / NIST / OPA Gatekeeper / Chrome-Blink / KEP /
  ModSecurity / RFC 5848 / RFC 9162 **复述不计入检索面**(承 forge-config Z 段原有约束);
- P3R1 标分歧时,**双方须各自点名「我的哪条 P1 判断被自己的 P2 检索推翻或改写」** ——
  一条都没有的一方,须在 P3R1 显式说明为何检索对自己零影响(这是 v2/v4 破回声的实际机制)。

**② 本条 binding 自身的歧义,登记为元层第⑥题的活体标本。**
