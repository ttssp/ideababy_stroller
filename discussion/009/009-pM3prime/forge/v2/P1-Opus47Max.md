## §1 现状摘要(按 Y 视角)

### 1.1 【验证方法学/认识论】本轮的触发事实**不是新信息** —— 它在 v1 自己的 X 里

这是我读完最意外的发现,也是我认为 v2 必须先摆正的一件事。

`risks.md` E1-R2 的下游后果注(**日期 2026-07-23**)白纸黑字写着:

> 凑不出 D-7 要求的领域独立真人第二源(**operator 自评标注质量不如 LLM · 无合格金融判断**)

而 `risks.md` **就在 forge v1 的 X 清单里**(v1 stage doc §Intake recap 第 6 项,标注读
「E1-R2 + 原始 G-R1 echo-chamber 先例」)。**v1 读过这句话,然后仍然收敛出「operator 可自任第二源」。**

所以 operator 07-27 的自陈**不是新证据到达**,而是**同一事实的复述**;真正改变的是:
**operator 拒绝接受 v1 对这个事实的重新解释。**

这把 v2 的题目从「处理新信息」改成了「**裁决 v1 的中心推论**」。两者要求的审阅动作完全不同 ——
后者必须把 v1 的推论拆开逐环节检验,而不是把新事实喂进旧框架再跑一遍。

### 1.2 【验证方法学/认识论】v1 中心推论的断点:度量函数的领域中立 ≠ 标注劳动的领域中立

v1 的关键一步在 stage doc L113-117:

> **Layer-2 第二源实际要做的工作,不是「懂投资」。** `mapping_agreement_rate()` 不含任何金融理解逻辑…
> 这解释了为什么「operator 不懂投资」不是全维阻断 —— 事实维度(ticker/交易所)可外证据核验,不需领域深度。

我认为这里有一次**范畴替换**:`mapping_agreement_rate()` 是一个**比较器**,它当然不含金融逻辑 ——
它只做 `==`。但**要被比较的那两组五元组是怎么产生的**,才是劳动所在。从一句「看好存储主线」
或一段直播转写里判定 direction / horizon / sector,**正是领域判断**。
「比较器是领域中立的」推不出「标注是领域中立的」。

v1 用「事实维可外证据核验」把这一步撑住了,但那只覆盖 ticker(watchlist 外锚)与 timepoint
(`published_at`)**两维**;direction / sector / horizon **三维**没有任何外锚,v1 也没给。
所以 v1 的论证严格讲只支持「**两维**不需领域深度」,却被用作「**五维**都不阻断」的结论。

### 1.3 【验证方法学/认识论】v1 契约的结构性空洞:gold 的来源从未定义

v1 的 D-7 改写草案(stage doc L168-183)对**第二源(human)**的资格写得很细:独立盲标 / 外证据
锚定 / 任务内校准 / abstain / 仲裁留痕。但**通篇没有一个字定义 gold 从哪来** ——
而它同时把验收判据改成了「逐维**双错率**」,双错 = machine≠gold ∧ human≠gold。
**双错率是相对 gold 定义的;gold 未定义,则整个判据悬空。**

这不是吹毛求疵:正因为 v1 没定义,operator 才不得不在 2026-07-25 临时拍板补协议
(gold=考据版 / human=盲标版 / machine=extracted_signals),而这个补丁**直接生产了本轮的困境**——
gold 与 human 同为一人,共享盲点;而且该协议**直到 D-3(本次 28 条决议)才被要求写进 spec/SLA**。
一个把错误率定义在未定义真值锚上的契约,**在结构上就是不完整的**,不是执行时才出问题。

### 1.4 【统计效力与可证伪性】能力缺口会**从另一扇门**重建门槛不可达

这是我认为 v2 最需要带给双方的技术发现,它**独立于**已决的 D-1。

一个诚实的低领域能力标注者,面对没把握的维度,**正确做法是 abstain**(D-7 明确鼓励:
「无法判断须 abstain」)。但 `coverage_denominator` = 非弃权且 gold 有值的计数,
而 SLA 冻结覆盖率门槛是 sector/horizon **0.75** · direction **0.80** · ticker/timepoint **0.90**。

于是:**弃权是能力不足时唯一诚实的动作,而覆盖率门槛惩罚弃权。**
sector 只要弃权超过约 1/4 就直接毙。换句话说 ——
**即使 D-1(a) 修好、即使找到了一个主体,只要那个主体在解释维上诚实,他仍然过不了覆盖率关。**

D-1 是「粗一致率 × 覆盖率」互斥;这一条是「**诚实弃权 × 覆盖率**」互斥。
前者是代码 refactor 没清干净,后者是**能力前提与验收设计的结构冲突**,改代码解决不了。
我认为 v2 若不处理这条,即便给出了新主体方案也会在真跑时再撞一次墙。

### 1.5 【统计效力】n=41 的效力本来就薄

41 条 × ticker/timepoint 双错率门槛 0.05 → 约 **2 条错**就翻盘;弃权还要从分母里扣。
在这个量级上,「提取器合格」与「提取器不合格」的判别力非常有限。
这不是反对做金标,而是提醒:**降级方案若进一步缩小验收面(比如只留事实维),
剩下的统计效力是否还足以支撑 E2 的开发证据地位,需要正面算,不能默认。**

### 1.6 【成本与 v0.1 可行性】还没被算过的一件事:Layer-1 面临同一个主体问题,但门槛低得多

`spec.md` L325 显示 **Layer-1 门槛仍空 = blocked-on Layer-1 真盲标跑**。
即 Layer-1(span 抽取:α + P/R/F1)**同样需要第二标注源**,同样没跑。
本轮 hand-back 和第 28 条决议都只谈 Layer-2,**Layer-1 的主体问题被整条链忽略了**。

但两者的能力要求不对称:Layer-1 问的是「**这句话是不是一条疑似信号句**」——
接近阅读理解;Layer-2 问的是「**这句话映射成哪支票、什么方向、什么期限**」—— 是领域判断。
如果整条 gold 链还有能活的部分,**最可能是 Layer-1**。这是我目前看到的最实的一条降级候选,
也是 v1 已经提过但被淹没在「operator 可自任」结论里的那条(v1 decision matrix「保留 · Layer-1
接受第二标注者算 α/span F1 · 是短期可交付面」)。

### 1.7 【成本】一条会咬到下游的 spec 不一致(非 D-1 重开 · 是它的后果)

`spec.md` O8 的验收终点写死为 `SELECT mapping_agreement_rate FROM gold_layer2_result` vs 门槛。
而 D-1(a) 恰恰要把 `mapping_agreement_rate` 从新契约路的 passed 合取里删掉。
**O8 的 Outcome 定义与即将落地的新契约会对不上。** 这不在本轮议题内,但 D-3 的定义补全
必须一并处理,否则 spec 的验收终点指向一个不再决定 passed 的数字。我在此记录,供 decision-list 收口。

## §3 我现在最不确定的 3 件事

1. **「不具备领域判断力」是否真的连 gold(考据版)都产不出?**
   operator 说的是**盲标**没把握。但 gold 是「读全文 + 查外锚 + 慢核」的考据版 —— 慢速、可查资料、
   可反复核对的条件下,能力边界可能显著不同于快速盲标。**如果 gold 可产而 human 不可产,
   整个困境的形状就变了**(变成缺 human 而非缺 gold)。这一条我在 P1 无法判定,需要 operator 澄清或外部方法学依据。

2. **是否存在「不需要任何人产真值」的验收范式?**
   我知道方向存在(事后结果回标 / 弱监督 / 无参考评测),但**不知道它们在 n=41、隐性指称、
   单人 v0.1 这三重约束下是否还剩效力**。这是 P2 的头号检索任务,也是「诚实 STOP」与
   「有路可走」的分水岭。我不预设答案。

3. **诚实 STOP 的代价到底有多大 —— 即 Layer-2 若判不成立,E1 的 ROI 是否真的归零?**
   v1 的 [Z] Abandon 段主张「放弃 Layer-2 = 密度达标但信号质量永不验 = 毁 E1 ROI」。
   但 E1 已经产出了一个**独立成立的正面实证**(~23/29 真隐性信号被口径捕捉,US 密度 go)。
   这个实证的价值是否真的必须由 Layer-2 背书才成立?
   **如果不必须,那「诚实 STOP」的代价远比 v1 说的小,verdict 就该更敢停。** 这直接决定 K 里那句
   「宁可接受诚实 STOP」能不能被兑现,我认为是 v2 最需要算清的一笔账。
