## 1. 现状摘要(按 Y 视角组织)

### 验证方法学/认识论

E1 将 span 发现与 sector/ticker/direction/horizon/timepoint 五维可交易映射拆成两层；D-7 用真人第二源与仲裁避 echo-chamber。X 把 G-R1 记作双 LLM 共享直觉、虚高一致性的先例，却未给模型谱系、样本设计或错误相关统计。因此它记录的是“第二个 LLM 不自动构成独立验证”，并未在 X 内记录“任何异源模型对都不独立”的观测。PRD/spec/risks 同时用真人代理来源独立性与领域正确性，两者没有被拆开。

### 架构设计

Layer-1 接受第二标注者，计算 α 与 span P/R/F1；Layer-2 以 `second_source_kind == "human"` 挡非真人，再按序逐项计算映射率，并保存 source id 与仲裁说明。该检查验证来源类别，不验证领域能力、与提取器的实际独立性或错误相关性；可审计“谁标了”，不覆盖第二源是否在关键漏错上真的互补。O7/O8 未跑时 gate 保持 fail-closed；harness、结果表与接入路径已就位。

### 产品价值

真实用户是单人、不懂投资的 operator。US 密度已过线，Layer-2 却因无合格真人停在“待第二源·未验收”，E2 不解锁。现状保住密度普查资产与不自欺的 STOP，尚未交付用户故事要求的第二个真数字“提取器是否可靠”。handback 将治理选择留在放宽、替代验收、寻找真人三方向；第二源到位后现有资产可接续运行。
