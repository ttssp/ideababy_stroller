# P3R1 — GPT-5.5 xHigh 初始裁决

## §1 · 综合摘要

双方事实面已收敛：C4 当前只测 literal proposer，不能证明系统稳定；DeepSeek 无调用方 seed，`system_fingerprint` 也不保证逐次复现，故单次输出不能作事实。SLA 已规定连续失败 hard-fail，补有界语义重试是在实现既有契约，并非改约。ledger 病种粒度只是追溯缺口，不足以回滚路线。现有资料没有可照抄的 N、阈值或聚合规则，必须预注册校准；聚合虽可能提高一致性，也可能滤掉边界信号。

唯一实质分歧是探针能证明什么。它可测跨次信度、候选选择频率与候选留存；但若无独立 validity 锚，且 41 条盲标路已 CLOSED，就不能自行产出“边界真信号留存率”。此时只能报告“预注册边界候选留存率”，不得把代理量改名为真值效度。

## §2 · 初始裁决

E1 路线暂不改判，但单次语料立即失去事实地位，扩样与 E2 继续 blocked。
先按现有 SLA 补有界语义重试；C4 v0.1 改为无 pass 语义的强制测量、申报、落库义务，并绑定模型与语料身份。
允许一个有界、预注册的聚合探针进入 verdict，但 R2 必须钉死四类上限、单命令和 pass／fail／indeterminate 三态判据；它只能测信度与候选留存，不能在无 validity 锚时自称测得“真信号留存”。
CN/HK 改判为 measurement-invalid／unknown 下的 fail-closed STOP，不再称“真稀疏”。

## §3 · 分歧与 R2 收敛条件

### 1. 立即探针，还是先解 construct hinges

- **我方**：同意立即做一次探针；两个 hinge 可作输出，但 validity hinge 必须有独立真值锚，否则只能测候选留存。
- **A 方**：“两个 hinge 本来就是 probe 输出。”信度成立；模型重复输出不能兼任预测与真值。
- **R2 收敛**：预先固定 N 上限、记录数上限、单次总时长上限、总成本上限、唯一命令、输入与模型身份、原始及聚合落库位置，并逐项规定 pass／fail／indeterminate。若报告真信号留存，还须事前命名独立标签来源。任一条件未钉死，我方反对探针进入最终 verdict。

### 2. C4 v0.1 是 report-only，还是新门禁

- **我方**：明确 `pass_semantic: none`。强制的是运行、申报、落库和身份绑定，不是用未校准数字新建门槛；既有 blocked 状态仍由原裁决维持。
- **A 方**：“v0.1 是 report-only。”同意，但 report-only 不等于 optional。
- **R2 收敛**：未来门禁必须升版，并在看相关结果前预注册口径、阈值、适用模型与校准样本。

### 3. CN/HK 撤销 STOP，还是改变性质

- **我方**：选择改变性质，不撤销执行态。原“true sparse”判断作废；认识态改为 measurement-invalid／unknown，STOP 仅代表测量失效时 fail-closed。
- **A 方**：“不撤销 STOP；改变理由。”同意；理由只许来自科学有效性，不得诉诸市场价值或商业优先级。
- **R2 收敛**：ledger 同存执行态 `STOP` 与认识态 `UNKNOWN`，记明旧理由失效证据及科学重判触发条件。
