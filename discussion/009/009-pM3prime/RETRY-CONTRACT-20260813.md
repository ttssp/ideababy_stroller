# 实现契约 · verdict (a) 有界语义重试 · **A + 判据 + 证不出则 B**

## 0. 这份文件是什么

forge v3 的 verdict (a) 只写了「补有界语义重试」,**没写重试几次、退避形态、以及重试没用时怎么办**。
`§underweights 第 1 条`把这判成「本轮最像 forge v1 失败模式的一处」,登记为 `OB-009-pM3prime-v3-11`。

本文补齐它。形态承 memory `forge-verdict-vs-empirical-ship` 的正面解法:
**实现选择类条款写成「A + 判据 + 证不出则 B」,并在 build 侧预置同轴熔断** ——
实证触发时**切换 = 契约执行**,零治理开销,不需要再起一轮 forge。

**本文不是**:不改 KG-40 的意图 · 不改冻结参数 · 不解锁扩样或 E2 · 不触碰 verdict (b)(c)(d)。

---

## 1. A · 主路径规格

**在宣告一条 record 失败之前,对下列三类做应用层重试:**

| 失败类型 | 现状 | 为何要重试 |
|---|---|---|
| 空 content(`api_failure`) | 首次即计失败 | SDK 默认重试**不覆盖** —— HTTP 200 + 空补全不是传输错 |
| 坏 JSON / 结构漂移(`parse_failure`) | 首次即计失败 | 同上;实测该失败**重试 3 次未复现**(PREREG §10.4 问题 1) |
| `usage` / `completion_tokens` 缺失(`parse_failure`) | 首次即计失败 | 同上 |

**不重试**(保持现状):`truncation_failure`(`finish_reason ≠ stop` / 撞满 `max_tokens`)——
它是**预算问题不是瞬态问题**,重试只会重复撞墙。

**参数**

| 项 | 值 | 依据 |
|---|---|---|
| **总尝试次数 `k`** | **3**(首次 + 2 次重试) | PREREG §10.4:那条失败 record 重试 3 次一次都没复现。且 `p_first ≈ 0.2%` 下,k=3 的期望额外调用 ≈ **0.4 次 / 102 条批**,成本可忽略 |
| **退避** | 指数:`1s` → `4s` | 失败类型是空/坏输出,**不是限流** ⇒ 长退避无意义;但须非零,以跨过瞬时服务抖动。⚠ **此形态无实测依据**,见 §7 |
| **耗尽后** | **照旧 hard-fail**,计入原三类计数 | KG-40 不动:重试耗尽仍失败 ⇒ 该 record 进入失败路径 |

**A 的适用边界**:重试解决的是 ②(fail-closed 在规模下不可跑),**不解决** ③(同日 Jaccard 0.44)。
两者是不同的失效面,不得混为一谈。

## 2. 判据 · A 到底成不成立

> **判据必须在跑第一批时就能算出来,否则它不产生行为**(承 forge 006 v10:无消费点的判据 = 没有判据)。

### 主判据(结构型 · 不需要阈值,小样本也有力)

**重试耗尽仍失败的 record,逐条看它是不是同一条。**

| 观察 | 判定 | 含义 |
|---|---|---|
| 每次失败的是**不同** record,且重试后**都过** | **A 成立** | 失败是瞬态的,重试是正解 |
| **同一条** record 反复失败(跨批次、跨重试) | **A 不成立** ⇒ **切 B** | 失败是该 record **固有**的(脏数据 / 编码 / 长度 / 内容触发过滤),重试治不了 |
| 混合:一部分瞬态、一部分固有 | **A 部分成立** ⇒ **对固有那部分切 B** | 两条路并存,按 record 分流 |

### 辅助判据(比较型 · 不拍绝对阈值)

`p_final`(重试耗尽后仍失败的 record 比例)**对比** `p_first`(首次尝试失败率):

- **`p_final` 比 `p_first` 低一个数量级以上** ⇒ 与「独立瞬态」一致(理论上 `p_final ≈ p_first^k`)
- **`p_final ≈ p_first`** ⇒ 重试没起作用,**切 B**
- **两者都太小以致算不出比值**(失败数 0 或 1)⇒ **`indeterminate`** —— **不得当作 A 成立**,
  按主判据(有没有同一条反复失败)裁,并在下一批继续观察

⚠ **`p_first` 的已知实测值**:`0.17% – 0.25%`
(593 条 1 次失败 = 0.17%;若计入 repro attempt#1 的那次 `api_failure`,约 797+ 条 2 次 ≈ 0.25%)。
**这是观察值不是承诺值**,不得写成阈值。

## 3. B · 证不出则 B —— **三态 record + 区间密度**

> B 的设计约束:**不得放松 KG-40**(失败绝不能被当成「真的没信号」),
> 但也**不得让整批因为一条固有失败而作废**。

### B.1 record 从二态改三态

```
现状:  has_signal | no_signal              ← 失败被迫塞进「整轮作废」
B:     has_signal | no_signal | unknown    ← unknown 是一等状态
```

**`unknown` = 重试耗尽仍失败的 record。它绝不被计为 `no_signal`** —— 这一条就是 KG-40 的全部内容,
B 保留它,只是不再用「整轮作废」这一种手段来保留它。

### B.2 密度从点值改区间

```
密度下界 = accepted                          （已确认的信号）
密度上界 = accepted + (unknown 条数 × 该层每条最大可能信号数)
```

保守起见,上界的「每条最大可能信号数」取该批 **已观察到的每 record 信号数上界**(而非 `_N_MAX`)。

### B.3 判决从二值门改三态(复用**已冻结**的 `density_threshold`,不引入任何新数字)

| 区间与阈值的关系 | 判决 | 说明 |
|---|---|---|
| 区间**整体 >** 阈值 | **`go`** | unknown 再怎么填都改不了结论 ⇒ **不受影响,不必作废** |
| 区间**整体 ≤** 阈值 | **`stop`** | 同上 |
| 区间**跨过**阈值 | **`indeterminate`** | 读数不足以支撑判决 ⇒ **这才是 `census_invalid` 的现代形态** |

**⭐ 这是本契约最关键的一步,请注意它为什么合法**:
B **没有引入任何新阈值** —— 它复用 `density_threshold`(E0 已预注册冻结),
只是把「拿点估计和阈值比大小」换成「拿**区间**和阈值比位置」。
⇒ **形态改,不是挪数字**(承 forge v2 判据),因此**不需要新的 `caliber_version`**。

**⭐ 而且它与 verdict (c) 聚合探针的三态判据同构**(`pass` / `fail` / `indeterminate`),
两处对「读数不足以判决」的处理方式一致,不是各写各的。

## 4. C · B 也不成立时的出口

若 `unknown` 多到**区间几乎总是跨过阈值** ⇒ 结论是:
**这批语料在当前提取器下不可判**。

出口 = **触发 forge v4**,与 verdict (c) 的 `M1 = fail / indeterminate` **同一个出口**。
⚠ **不得**在执行侧「调一下上界估计法把区间压窄」—— 那是把判据往结论上凑。

## 5. 记账要求(判据算得出来的前提 · **不做这条,前面全是空话**)

| 必须记 | 为什么 |
|---|---|
| 每条 record 的 **`attempts`** 与每次的**失败类型** | 没有它,`p_first` / `p_final` 都算不出来 |
| 每条 record 的**终态**(`has_signal` / `no_signal` / `unknown`) | B.1 三态的载体 |
| 失败 record 的 **`source_id`** | 主判据「是不是同一条」的唯一依据 |
| 每次调用的 `system_fingerprint` / `service_tier` | 与 verdict (b) 的身份绑定同一份记账,**不重复实现** |

⚠ 这份记账与 **v0.2 note 2(`trial_ledger` 新 grain)有接触面** ——
但**本契约只要求把上述字段落库到可 `SELECT` 的地方,不要求现在就改 `trial_ledger` 的 grain**。
grain 改动会动 DSR/PBO 分母语义,forge v3 已明确判为「不宜顺手改」。**不要顺手改。**

## 7. 明确未实证的部分(诚实交代 · 不得被读成已验证)

1. **退避形态(`1s` → `4s`)无任何实测依据。** 它是猜的。若实测显示重试成功率与退避时长无关,
   应简化为固定短退避;若显示相关,才值得调。**本契约不预设哪个为真。**
2. **`k = 3` 的依据是 n=1 的观察**(一条 record 重试 3 次未复现)。它是个合理起点,**不是标定结果**。
   §2 的主判据会在第一批真跑时给出是否够用的证据。
3. **B 从未被执行过。** 三态 + 区间密度是设计,不是实证。首次触发 B 时应产 hand-back 回 IDS。
4. **本契约整体零 build 侧实证** —— 与 forge v3 同一局限(见 stage doc §underweights 第 1 条)。
   它的价值在于:**实证到来时,切换是契约执行而不是新一轮治理。**
