## §1 · SOTA 对标

| 主题 | SOTA 发现 | 对 009 v5 的含义 |
|---|---|---|
| **LLM 权重面 look-ahead**(P1-Opus 不确定点 #2) | 已是**命名问题**:"parametric look-ahead bias"——模型权重内嵌训练窗内的未来知识,数据管道审计不可见。实证:Llama 2 对 2019 年财报会做风险预测,25%+ 提到 Covid;GPT-4o 能近乎完美复述训练窗内标普收盘价与 WSJ 头条日期。**理论结论:若模型记住了结果,预测能力不可识别**(分不清预测还是回忆)。缓解先例:按发布时间切断语料、**rationale 必须引用决策时点前已发布的证据**、embargo 窗、按时间分片训练的 PIT 模型(DatedGPT 类)、跨模型分歧过滤(MemGuard 类) | ① P1-Opus 的"引文锚定"缓解与 SOTA 最佳实践一致,升格为硬约束;② **不可识别性定理改变验收语义**:落在模型训练窗内的历史回测只能算"假设生成",不能算"确证"——真确证要靠 **forward 评估**(内容到达即提取、封存、事后对答案,零权重泄漏)。009 语料 2025-06→2026-07,尾段已在多数模型 cutoff 之后,且未来增量语料天然干净 → 架构上应把 forward 线设为主证据线,历史窗降级为开发/校准用 |
| **文本→交易信号提取 prior art** | 新闻情绪 alpha 领域结论:信号可提取、常统计显著,但**经常不赚钱**(有事件标签稳定负 alpha 的实证);LLM 情绪打分存在**聚合不稳定**——同一文本因 prompt 结构/温度不同给出矛盾分数;PIT 数据结构被公认为回测效度前提 | ① 统计显著 ≠ 有用,M2 的 DSR/PBO+成本项已防这个,keep;② **提取器稳定性是新的工程纪律面**:温度 0、prompt 版本化、同文本多次运行一致性检查,否则 trial_count 记账都数不清楚——这是 operator 两条红线之外 SOTA 给出的第三个泄漏面 |
| **"给公开言论的 guru 打分"直接先例** | CXO Advisory **Guru Grades**:2005-2012 人工收集 68 位专家 6,584 条公开预测并评分——方法论核心与 009 同构(从 essay/评论中提取可评分预测);**规范:"太模糊无法评分的预测直接排除"**;基线结论:平均准确率 <50%(约等于抛硬币);概率化表述用 Brier 评分 | ① 009 的"提取层 rejection taxonomy"(P1 双方各自独立提出)有直接先例背书——vague→exclude 是该领域规范,不是我们的发明;② **基线预期要校准**:公开 pundit 平均是硬币水平,operator 对该分析师的正面体感属幸存者视角,M2 数字出来前不给先验加分;③ TipRanks 三件套(v1 锚)适用显性荐股,CXO 范式才是隐性言论的正确参照 |
| **gold-standard 标注验收方法** | 成熟方法论:标注指南 + 专家金标集 + 分歧仲裁;一致性阈值 **Krippendorff's α ≥ 0.667**;span 级 P/R/F1;"一致性指标会掩盖具体错误源,必须人工复看分歧 case" | P1-Opus"提取质量独立验收"红线可直接落成可测口径:金标小样本(operator 本人标注 + LLM 独立标注 + 仲裁)、α≥0.667 门槛、提取器 P/R 先过门槛再进回测——联合假设拆账(P1-GPT #3)有了具体机制 |

## §3 · 修正后的视角

**站住的**:P1 全部主判保持——M1/M2 量尺 keep、smoke path cut、提取头/蒸馏技能拆分、
两条红线、008→004 桥=提取头。对方 P1 与我独立收敛,SOTA 无一处推翻共识,只做加固与具体化。

**被加固/升级的**:
1. **权重面 look-ahead 从"我最担心的未知"变成"有成熟对策的已知"**,但代价是验收语义要改:
   历史窗回测降级为假设生成,**forward 评估线成为 alpha 确证的主路径**。这是 P1 没有的结构性
   新知,直接影响 M3' 的分期设计(历史窗先导实验 → forward 采集-封存-对账机制常设化)。
2. **提取器稳定性**(同文本同版本必须同输出)加入工程纪律清单,与 trial_count 记账互为前提。
3. **金标验收有了具体数字口径**(α≥0.667 / span P/R/F1),operator 本人可当标注者之一。
4. **基线预期锚定**:CXO 实证说公开 pundit 平均 = 硬币。009 的诚实叙事应该是"我们要用
   CXO 级方法 + 现代统计纪律,检验一个私域分析师是否是例外",而非默认他有 alpha。

**留给 P3 的分歧候选**(与对方 P1 对比,暂无硬冲突,但有侧重差):对方强调"标注口径本身
决定回测结论"(sector/ticker/方向/horizon 的映射口径),我强调"物化路径与 forward 线架构"。
两者互补,P3R1 需合成:**口径(什么算一条疑似信号)先于架构(它落哪张表)**,建议 P3 按
"口径 → 验收 → 物化 → 分期"顺序收敛。
