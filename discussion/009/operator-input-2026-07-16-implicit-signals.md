## 2. 事实修正的核心(一句话)

**该分析师不产显性荐股 call;信号只以隐性形态存在**(盘前/盘中/盘后笔记里的零散
关键信息披露、直播里的展望/预警、只言片语甚至暗示)。M2 alpha 头的输入假设
"存在显性 (ticker, direction, date) 信号"对该数据源**永久不成立**——不是"数据没填",
是"该形态的数据不存在"。

## 3. 对既有决议/资产的影响

### 3.1 被 supersede 的决议

- **07-07 决议 1(smoke path)**:前提是"显性历史 call 存在,只缺搬运"。前提已破,
  该决议作废。M3 go/no-go 原判据("M2 样本量够不够 DSR 显著")在原形态下**不可达**。

### 3.2 缺口升级

- GAP-1 从"缺 008→004 backfill 搬运桥"升级为"缺**信号提取/蒸馏头**":
  008 内容库 → 从笔记/直播转写中提取"疑似信号"并显性化(ticker / 方向 / 时间 / 出处
  / 置信)→ 才能进 M2 评估机器。
- 原 forge v1/v2 把"蒸馏"排在 **M4 最末且 gated**("蒸馏最后且只能独立 lane 化");
  operator 真实需求把它提前到**任何评估之前的关键路径**。这是路线图倒转 =
  重大架构转向,按宪法必须走 forge 裁决,不得在 build runtime 自行起工。
- 评估问题从"这个分析师行不行"变为"**分析师隐性信息 × 提取方法**"的联合假设
  ——009 实际要造的是"学会他怎么看盘"的解读器,回测是解读器的考官。

### 3.3 不变的资产(量尺,全部照用)

- 004 纪律壳 / 008 采集的上下游定位不变。
