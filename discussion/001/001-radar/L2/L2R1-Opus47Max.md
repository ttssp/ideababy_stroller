## 1. The idea, unpacked

用户不是"研究者"这个泛称，是一类很具体的人：**AI lab 的负责人**——手里同时罩着 8~15 个 topic，自己动手写代码的时间趋近于零，但每周要做的决策全都依赖"对领域现状的判断"：批不批一个新课题、砍不砍一个旧方向、给哪个学生的 proposal 泼冷水、下季度的算力往哪儿压。这个人的困境不是"读不完论文"——那是 PhD 的困境——而是**他对每个领域的 big picture 在悄悄过期**。他上一次真正吃透 RLHF 是八个月前，之后的理解全靠走廊对话、Twitter 碎片和组会上学生的转述拼起来。他自己知道这一点，所以每次做方向判断时心里都有一丝不确定：我脑中的这张地图，还是现在的地形吗？

有了这个东西之后，他的动作变成：**想查的时候打开那个 topic 的地图**。地图不是引用关系的可视化，是一张**方法级**的知识图谱——节点既有 paper 也有"方法/技术"这种更耐久的单位，边是 derives-from / contradicts / generalizes / supersedes。而且地图是**活的**：一个 agent 在持续收集最新 SOTA 工作、判断价值、把有价值的织进图里、给价值一般的留痕防漏。他看到的第一屏不是图本身，是**位移**：过去 90 天，这个领域哪些假设在退潮、哪些方向被合并、哪个新节点正在往中心挤。

aha 时刻是 Direction 7 给的那个场景的通用化：你打开一张自己三个月没看的地图，radar 把这三个月的位移画给你——"frontier 从 DPO 往 online 方向漂了 40 度"——你本来**隐约感觉到**了这件事（Twitter 上似乎这类工作变多了），但从来没有人把它**画出来**给你确认。那种"我模糊的直觉被具象成一张可以指着讲的图"的瞬间，是这个产品的第一价值时刻。位移比新增更有信息量：新增是流的逻辑（今天又有 40 篇），位移是地图的逻辑（重心挪了、某条边断了）。

六个月后的熟练用户不再把它当查询工具，而是当**判断的外骨骼**：季度方向复盘时逐张地图过位移；学生开题前先让他在地图上指出自己的 idea 落在哪个区域;请报告嘉宾前先看对方的工作在图上的邻域。更重要的是 agent 的品味在和他对齐——哪些位移值得推到他眼前、哪些只是噪声，这个判断在长期交互中被校准。原提案的终局野心（lab 的 research agent，自己找题目做实验）在这里露出第一级台阶：**对现有工作的深理解是想出好题目的前置条件**，这张持续演化的图就是那个"深理解"的物质形态。

如果一百万人用它，"这个领域现在怎么样"会从一种口口相传的软知识变成一个可打开、可指认、可争论的公共物件——survey 从半年一篇的静态快照变成活的地层图。但这是远景，不是承诺。

## 2. What's genuinely novel

诚实地说：**零件都不新，组合方式新**。citation graph 可视化已有成熟产品（Connected Papers / Litmaps / ResearchRabbit）；新论文 alert 也是十年老功能。真正没见过的核心是三件事的叠加：(a) **节点升到方法级**——现有图的节点是 paper，而"方法/技术"才是研究者真正思考的单位，paper 只是方法的证据载体；(b) **位移是产品的 payload**——现有工具给你一张静态邻域图，这里的主呈现是**两个时间切片之间的 diff**，图本身反而是底图；(c) **agent 持续策展**——不是"给一篇种子论文长一张图"的一次性生成，而是一个有品味、可校准的 agent 在持续决定什么值得进图。三者单拿哪个都能找到近亲，叠在一起的产品形态我没有见过。但这个判断必须过 L2R2 的 2026 年 7 月行情检验——18 个月里这个赛道出新东西的概率不低。

## 3. Utility — 3 concrete usage scenarios

**场景一（invited talk 前夜）**：lab 负责人下月要讲 preference learning 的 invited talk。打开地图，位移视图显示 frontier 从 offline DPO 变体向 online / on-policy 方法漂移，且三篇工作在 contradicts 一个 2025 年的共识假设。这页位移图直接成为演讲里"field 往哪儿走"的关键 slide。事后他跟同行说的是："那张图不是我画的，是我的 radar 长出来的。"

**场景二（季度方向复盘）**：季度会前，他把 12 张地图的 90 天位移各看十分钟。发现自己 lab 押注的某方向，其中心假设在这个季度被三篇独立工作 contradicts——地图上那个节点的入边红了一圈。他带着这张图进会议室，砍方向的讨论从"我感觉这条路不太行"变成"证据在这儿，大家看"。问题消失的方式：方向决策从记忆和直觉的辩论变成对一张共享地图的核对。

**场景三（学生开题）**：学生兴冲冲提了个 idea。他打开对应 topic 的地图，两人一起找这个 idea 的落点——发现它坐在一个四个月前被 supersedes 边覆盖的区域，隔壁却有一条几乎没有节点的 frontier 边。原本要一周的"我回去想想"，变成十分钟的有据反馈加一个更好的方向。学生获得的不是否定，是**一张能看见自己位置的地图**。

## 4. Natural extensions

v0.1 立住之后最自然的下一步：**lab 共享层**——组里每个人在地图上留注记、认领节点，地图从负责人的私人判断外骨骼长成 lab 的共享认知底座（L1 菜单里 lab-scale 主题的回归）。其次是**区域订阅**："这个节点周边有任何位移就叫我"——radar 从被动查询长出主动提醒，但以地图区域而非关键词为订阅单位，这是 feed 类工具给不了的。再往后是**跨 topic 的方法迁移检测**（某方法从 NLP 图漂进 RL 图，往往是好题目的前兆），以及原提案写明的终局：把图作为 research agent 的底座——brainstorm 时 agent 在图上找空洞、找矛盾、找可迁移的边。每一级都以前一级的图质量为地基，不需要跳跃。

## 5. Natural limits

它**不该是每日简报**——那是 001-pA 的形态，砍窄给忙人看流的产品；地图的价值恰恰在"想查时打开"的 pull 语义，混进 push 会把它拖回 feed 的重力井。它**不适合领域新人**从零学起——位移的前提是你脑中有旧地图可以被 diff，新人需要的是 survey/教科书，这个相邻用户段看着近，其实是另一个物种。它**不该追求全覆盖**——把 arxiv 全量塞进图是 feed 思维的残留，价值在 8~15 个 topic 上的选择性中心度，贪全会同时毁掉品味和信任。它**不是真理机**——contradicts / supersedes 这类边本质是判断而非事实，地图必须把自己的不确定性穿在外面，否则一次显眼的错边就会烧掉全部信任（这是要带进 L3 的产品风险，不在本层展开怎么解）。时间尺度上它预设了 arxiv 速度的领域——半年位移接近零的慢领域里，这个产品的核心呈现没东西可画。

## 6. Three honest questions about this idea

1. **差异化是否在 2026 年 7 月仍然成立**：Connected Papers / Litmaps / ResearchRabbit 以及 18 个月里的新进入者（alphaXiv、Semantic Scholar、Elicit 一类），今天到底有没有做"方法级节点 + 时间位移"？如果有人已经做了一半，剩下的一半够不够撑一个独立产品？
2. **lab 负责人真的会基于图做方向决策吗**：还是他们的真实决策回路永远是走廊 + Twitter + 直觉，图再好也只是事后佐证？有没有需求信号（比如"state of X"类年度回顾演讲的受欢迎程度、trend dashboard 的真实留存）能证明"位移视图"有人愿意反复回来看？
3. **一张"被打开并据此做决策"的地图和一张"漂亮但没人看第二次"的 dashboard，分界线在哪**：L1R2 对 Direction 8 的警告（气氛≠决策）对本方向同样悬着——前人做研究趋势可视化的失败案例里，用户到底是在哪一步流失的？
