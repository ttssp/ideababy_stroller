### B. 重大设计决定(已由 operator 批准 · 供 IDS 存档,不需再决)

**文档身份 = 恒等映射(逐字),弃归一折叠。** 折叠版连续 **5 轮**被 codex 证出**可执行**碰撞
(query/fragment 被吞 → arXiv 版本与 DOI 尾斜杠被裁 → 空分隔符不可区分 → IPv6 方括号被剥 →
IPvFuture 不含冒号 → port 转 int 丢词法 → `urlsplit` 静默删控制字符)。根因是**「归一必须单射」
在通用 URL 上极难成立**,而同一 key 同时用于 anchor↔ref 一致性与 corpus membership,任一碰撞
都让未检索资源穿过两道门。恒等映射天然单射 —— 该证明义务整体消失。

前提**机器可验**(非假设):三方 ref 一次 run 内同源同串,已实地追链并用生产链绑定测钉住
(`test_verbatim_ref_identity_holds_across_the_real_production_chain`,fake LLM 故意返别名以证
builder 锚回原始串)。上游一旦改成让 LLM 自填 ref,该测立刻转红。

折叠版的全部碰撞用例**保留为回归网** —— 任何未来重新引入折叠都会立刻转红。

### D. 本轮最值得回流的**方法论**教训(非代码)

1. **「注释宣称的」与「代码做的」会分家,且分家处正是 bug 温床。** 本 task 抓到 3 例:arXiv 版本
   注释宣称「1-4 位」而正则允许任意长前导零;`anchorable` 注释宣称「anchor 可解析」而实为分支名代理;
   非 ASCII 放行的块注释在行为改后未同步。建议 review checklist 显式加「逐条核对注释断言」。
2. **测试可以「看着覆盖、其实零牙」,而且会集中在最核心的判据上。** 本 task 修前把 O2 **核心**的
   corpus membership 门整个关掉,716 条测试照样全绿 —— 根因是断言用中文子串而 fixture 的 claim
   文本恰好含该词。建议:blocker 加**稳定类别码**(枚举),测试断类别码而非中文子串。
3. **验证工具本身也会失去牙齿。** 本轮 mutation 判据两次写错(`"1 xfailed"` 含子串 `"failed"`),
   把「变异存活」误报成「被杀」。凡「全绿即通过」的判据,都要先证它在**该红时真红**。
4. **为图省事发明数值界 = 反复栽跟头。** arXiv 版本位数(两头都错)、DOI 前缀 `{4,9}`(无出处、
   误拒真实 DOI)。规则:**没有权威出处的边界不要写**;真需要资源上限就作为独立策略显式声明。
