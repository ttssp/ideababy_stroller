## §2 触发原因 + 决议链(按 frontmatter `tags` 逐条说明)

**tag = prd-revision-trigger** — spec 内部两条 outcome 的**字面契约矛盾**(非 PRD 不可达 · 而是 spec 派生的两条 outcome 互相冲突,需 IDS 裁定 SSOT 优先级 / 加豁口条款)。

### 矛盾的两面(spec 原文引证)

| # | spec 条款 | 原文(逐字) | 对稀疏判断的裁决 |
|---|---|---|---|
| A | §1 O2(spec.md:67)| 「**任一** briefing 的**任一**判断,operator ≤3 次点击/跳转到达支撑它的节点/边/真原文出处;且 `source_ref` **可解析到真检索到的文档**」 | 稀疏判断无节点/边/真原文 → **违 O2** |
| A' | §6 证据链强制(spec.md:82)| 「**每条判断** 3 击内到原文 + 低置信显式标注」 | 「每条」无例外 → 稀疏判断**违** |
| B | §1 O4(spec.md:69)| 「低置信处**显式标注**不确定度(**不做真理机**)」 | 稀疏判断标 low_confidence=True → **合 O4** |
| B' | OUT-8(spec.md:97)| 「**无证据判断必须标低置信**(O4)」 | 无证据 → 必标低置信 → 稀疏判断 evidence=() 合规 | 

**关键盲区**:B/B'(OUT-8)说「无证据 → **必须**标低置信」,但**没有**说「低置信 → **豁免** O2 证据链」。A/A'(O2)说「每条判断都要 3 击」,没有「低置信除外」。两者在**稀疏方向**(low_confidence=True ∧ evidence=())这一格**直接对撞**:该判断同时(合 B/B')且(违 A/A')。

### 触发场景(真跑实证 · 非推演)

T020 judge 有两条合法产 `evidence=()` 判断的路径,均是 domain **明确支持**的输入:
1. **稀疏叙事**(`sparse_coverage=True`):reconstructor 切不出 ≥MIN_SLICES → `slices=()` · judge 稀疏退路诚实产 low_confidence 判断(judge.py:83-99)。
2. **无可锚 provenance**(codex round-8 P2 收口):非稀疏但图空 + 全切片无 `source_refs`(均 domain legacy 形态)→ `anchor_map` 空 → judge 前置退路产 low_confidence 判断(judge.py:~110)。

两路径产的判断均 `low_confidence=True ∧ evidence=()`。codex round-10 P1(judge.py:99-101)精准定位:「低置信标记并未在现有契约中豁免证据链」。

### 为什么不是 T020 代码错

T020 impl 是**诚实的**:稀疏/无 provenance 时**真的没有** provenance 可锚(挂任何图 ref = 伪造证据 = 违 OUT-8 真理机红线)。让 judge「为了满足 O2 而伪造一个证据链」恰恰是 spec 最反对的真理机行为。故 T020 在**两条 spec 约束不可同时满足**时选了「守 OUT-8 反真理机(诚实无证据)」而非「守 O2 字面(伪造证据)」—— 这是正确的价值排序,但它让 impl 与 O2 字面冲突,需 spec 层澄清。

### 已有 operator 决(XenoDev 内 · 待 IDS 追认或改)

round-6 codex 首次提此点时,operator 决「**T021(证据链强制 owner)对 low_confidence=True 且 evidence=() 判断豁口**(不当 ship-blocker)· 只对高置信/有锚判断强制 ≤3 击链」。此决**已写进 T020 judge.py 稀疏退路注释 + 契约测**(`test_should_emit_sparse_judgment_as_honest_evidence_free_low_conf` 等),但**未落到 frozen spec 字面** —— codex round-10 正是指此:决议是 plan,但 spec O2 字面未改,契约合法性悬空。本 hand-back 请 IDS 把该豁口**正式落 spec**(或裁定别的解法)。
