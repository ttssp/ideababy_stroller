**缺陷(真跑复现,非推演)**:

```
语料同含 https://repo.example/paper 与 https://repo.example/paper/(两篇不同文档)
LLM 明确返回      https://repo.example/paper
builder 实际锚到  https://repo.example/paper/     ← 静默覆盖 · 无异常 · 无日志
```

judge 原样复制该错 ref,enforcement 检查 membership 时**它确实在语料里** → **全链无 blocker**。
即 O2 的「3 击回溯真原文」在这条链上是**假的**:锚指向的不是支撑该判断的那篇。

**两层根因,两层修**:

1. **canonicalizer 越权折叠**(`credibility/gate.py`)—— 通用 URL 分支做无差别 `rstrip("/")`。
   该函数存在的理由是消 **DOI/arXiv 变体**的假 STOP(那些折叠由各自规范保身份),
   通用 URL 的尾斜杠**从来不在这个理由的射程内**。改为 path 逐字保留;DOI/arXiv 折叠**不动**
   (既有单元测 `test_canonicalize_doc_ref_maps_variants_to_same_key` 继续绿 = 未伤及初衷)。
2. **消费结构静默覆盖**(`graph/builder.py`)—— `{canonical: 原串}` 单层字典改为 `_RefIndex`:
   `exact`(原串逐字集 · **优先命中、不经归一**)+ `alias`(canonical→原串,**仅收唯一对应一篇**的;
   一对多**整条剔除**)→ 查不到即 **fail-closed 丢锚,绝不猜**。

**T021 的 strict xfail 完整兑现**:修好后该测自动 XPASS(strict) 报错,精确提示拆标记 ——
跨 task 跟踪钉的机制走通一整轮。marker 已拆,转常规回归测。

**验证**:全量 **730 passed** · `gate.py` 97% / `builder.py` 96% · ruff clean · mutation **8/8 全杀无存活**。
